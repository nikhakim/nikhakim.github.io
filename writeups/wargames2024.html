Unwanted Meow

forensics easy

We're given a file called flag.shredded. The name and extension don't tell us much, but the challenge hints that something has been deliberately corrupted. First step — figure out what the file actually is.

fig 1 — challenge description
fig 2 — the shredded file
vulnerability / technique

Binary junk injection — the JPEG file has had the string meow repeatedly inserted throughout its raw bytes, corrupting the image data. Stripping those bytes restores the original file.

1

Rename flag.shredded to flag.jpg and try to open it. The image opens but is clearly broken — visually shredded into unrecognisable slices. This confirms it's a JPEG with corrupted data, not a completely different file type.

2

Open flag.jpg in hexedit (or any hex editor) and inspect the raw bytes. Scattered throughout the file, we spot the ASCII string meow repeated over and over — this is the injected junk that's breaking the image.

fig 3 — hexedit revealing repeated "meow" strings in the binary
3

True to the challenge name — Unwanted Meow — we need to strip every occurrence of meow from the raw binary. A short Python script does the job cleanly: open the file in binary mode, replace all b"meow" occurrences with empty bytes, and write the result out.

python clean.py
# remove all "meow" bytes from the corrupted JPEG
input_file = "flag.jpg"
output_file = "flag_cleaned.jpg"

with open(input_file, "rb") as infile:
    data = infile.read()

cleaned_data = data.replace(b"meow", b"")

with open(output_file, "wb") as outfile:
    outfile.write(cleaned_data)

print(f"cleaned file saved as {output_file}")
terminal
$ python3 clean.py
cleaned file saved as flag_cleaned.jpg
4

Open flag_cleaned.jpg. The image renders correctly and the flag is visible inside it.

fig 5 — cleaned JPEG with the flag revealed
key concept — binary file manipulation

Image files are just structured sequences of bytes. Injecting arbitrary byte sequences (like meow) anywhere outside the header will corrupt the pixel data, making the image unreadable to viewers. Since JPEG doesn't have strong integrity checks, a simple byte replacement is enough to reverse the damage. This technique is common in forensics CTFs — always inspect files in a hex editor before assuming they're truly broken.
